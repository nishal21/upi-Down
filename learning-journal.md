# Learning journal

- PGlite socket server takes one connection at a time: set `DB_POOL=1` in dev or you get ECONNRESET.
- `REDIS_URL=memory` uses ioredis-mock (dynamic import, so prod image doesn't need it).
- Magic UI BlurFade triggers on in-view; inside scroll lists rows stayed invisible. A CSS `row-in` keyframe is cheaper and reliable on Android WebView.
- Radix Tooltip `data-state` overwrites Toggle's `data-state` when using `asChild`; wrap the Toggle in a `<span>`.
- Capacitor 8 SystemBars key is `initialViewportFitValueHint: "cover"`, not `initialViewportFitCover`.
- Capacitor Android serves from `https://localhost`, so the API CORS list must include it.
- On a shared VPS: Docker `cpus` + `mem_limit` + low `cpu_shares` plus an Nginx `limit_conn` on SSE keeps a viral spike from hurting other apps. Cloudflare 5s edge cache on `/api/status` absorbs most reads.
- Next `.env.local` overrides `.env.production` even in `next build`. Put dev values in `.env.development.local`.
- Radix Tabs defaults to `dir="ltr"`. Pass `dir` or RTL rows won't mirror.
- CSS overrides inside `@layer base` lose to Tailwind utilities. Keep per-language overrides unlayered.
- NPCI's site blocks bots. Fetch its JSON API from the page context in a real browser.
- Cloudflare's Turnstile test secret returns hostname `example.com` and no action. Allow it only when not in production.
- Status rule: down = ≥15 reports, ≥5× baseline, ≥50% failures; slow = ≥6 and ≥2.5×.
- Don't remount a hero with `key={headline}` plus a fade that starts at opacity 0. The first snapshot swap blanks the title. Animate transform only, keep the node.
- Split React context by write rate. Opening a drawer should not re-render the whole board.
- Next 16 `output: export` makes unknown `/[slug]` throw in `next dev` instead of `notFound()`. Set `output: "export"` only when `NODE_ENV === "production"` so local unknown URLs render the 404 page; `next build` still writes static `out/`.
- Soft “glow” orbs need real `filter: blur()` or they read as hard circles. Quiet/neutral tones disappear on cream; mix with ink or success.
- CSS marquee `transform` steals clicks while moving. Pause the animation on pointer enter before handling the bank chip click.
- Pull the hero out of `max-w-*` so the backdrop and ticker can go edge-to-edge; keep the headline in an inner max-width column.
- `Intl` `hour12` alone can still look ambiguous. Build the string from `formatToParts` and force uppercase AM/PM.
- AEO/GEO: put the answer question as a stable H1, duplicate FAQ in HTML + FAQPage JSON-LD, add Speakable cssSelectors, ship `llms.txt`, and allow GPTBot/ClaudeBot/PerplexityBot in robots. Metadata alone will not rank #1.
- WebSite SearchAction `urlTemplate` with `?q=` must be honored client-side or Google’s sitelinks search box breaks.
- Footer copyright year: `new Date().getFullYear()` in the client Footer is fine for static export (builds once; year updates on next deploy).
